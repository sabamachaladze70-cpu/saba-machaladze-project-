# GeoTours - საბოლოო პროექტი

ეს არის ჩემი საბოლოო პროექტი - მოგზაურობის პლატფორმა "GeoTours". საიტი შექმნილია მომხმარებლებისთვის, რომლებსაც სურთ აღმოაჩინონ საქართველო, დაგეგმონ ტურები და მიიღონ საუკეთესო მომსახურება.

## პროექტის სტრუქტურა
- `final-project/` - ძირითადი ვებ-აპლიკაცია (React + TypeScript)
- `README.md` - პროექტის აღწერა

## ფუნქციონალი
- ტურების დათვალიერება და ფილტრაცია
- ტურის დეტალური ინფორმაცია და გალერეა
- ჯავშნის სისტემა
- კონტაქტის ფორმა
- სრულიად რესპონსიული დიზაინი

## როგორ გავუშვათ
1. შედით `final-project` დირექტორიაში.
2. გაუშვით `npm install`.
3. გაუშვით `npm run dev`.
