# GeoTours - პრემიუმ სამოგზაურო პლატფორმა 🌍

GeoTours არის თანამედროვე, სწრაფი და დახვეწილი ვებ-აპლიკაცია, რომელიც მომხმარებლებს სთავაზობს საქართველოს ულამაზეს კუთხეებში დაუვიწყარ მოგზაურობას. პროექტი შექმნილია მომხმარებლის საუკეთესო გამოცდილების (UX) და მაღალი წარმადობის გათვალისწინებით.

## 🚀 ძირითადი ფუნქციონალი

- **ტურების კატალოგი**: დეტალური ინფორმაცია ტურებზე, ფასები და ხანგრძლივობა.
- **დაჯავშნის სისტემა**: ტურების დამატება კალათაში და ჯავშნების მართვა Redux Toolkit-ის გამოყენებით.
- **რესპონსიული დიზაინი**: სრულად ოპტიმიზირებული მობილური, ტაბლეტის და დესკტოპ ხედებისთვის.
- **თემები**: ნათელი (Light) და ბნელი (Dark) რეჟიმების მხარდაჭერა.
- **ძებნა და ფილტრაცია**: ტურების მარტივი მოძიება კატეგორიების და ძიების მიხედვით.
- **გარე API ინტეგრაცია**: მოგზაურების ისტორიების დინამიური ჩატვირთვა.

## 🛠 ტექნოლოგიური სტეკი

- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS (პრემიუმ ესთეტიკა და ანიმაციები)
- **State Management**: Redux Toolkit (კალათის ფუნქციონალისთვის)
- **Routing**: React Router 7
- **Build Tool**: Vite (ოპტიმიზირებული Manual Chunks-ით)
- **Icons**: Lucide React / SVG Custom Icons

## ⚙️ ინსტალაცია და გაშვება

1. დააკლონეთ რეპოზიტორი:
   ```bash
   git clone https://github.com/sabamachaladze70-cpu/saba-machaladze-project-.git
   ```
2. გადადით პროექტის საქაღალდეში:
   ```bash
   cd final-project
   ```
3. დააინსტალირეთ დამოკიდებულებები:
   ```bash
   npm install
   ```
4. გაუშვით დეველოპერული სერვერი:
   ```bash
   npm run dev
   ```
5. პროექტის დასაბილდად:
   ```bash
   npm run build
   ```
