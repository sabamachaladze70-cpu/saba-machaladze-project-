# MOUVELINE - რესტორანი

ეს არის ჩემი პროექტი - რესტორანი "MOUVELINE".

## როგორ გავუშვათ
```bash
git clone https://github.com/sabamachaladze70-cpu/saba-machaladze-project-.git

# შედით პროექტის დირექტორიაში
cd final-project

# დააინსტალირეთ საჭირო ბიბლიოთეკები
npm install

# გაუშვით პროექტი ლოკალურ სერვერზე
npm run dev
```
