# GeoTours - იმოგზაურე საქართველოში

GeoTours არის თანამედროვე პლატფორმა, რომელიც გთავაზობთ საუკეთესო ტურებს საქართველოს მასშტაბით. აღმოაჩინეთ ჩვენი ქვეყნის ულამაზესი კუთხეები, ისტორიული ძეგლები და დაუვიწყარი თავგადასავლები.

## ტექნოლოგიები
- React 19
- TypeScript
- Vite
- Redux Toolkit
- Tailwind CSS

## როგორ გავუშვათ პროექტი
1. `npm install`
2. `npm run dev`

## ბილდი
`npm run build`
